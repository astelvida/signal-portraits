Typography

Display · Fraunces variable, opsz 144, weight 400–500, italic for marks. UI · DM Sans variable. Data · JetBrains Mono, tabular numerals. Self-hosted via next/font.

Color discipline

Warm-white #FAFAF7 · Ink #0E0E0E · Vermillion #E63312 as the only accent — applied on the SSI score, active filter, hover state. No purple gradients. No glassmorphism. Grain layer at 4% opacity.

Determinism

Each portrait's seed = sha256(slug + thesis + ssi). Same inputs → same render. A new Signal in Notion shifts the score, which moves the visible structure. The portrait is the methodology made visible.
